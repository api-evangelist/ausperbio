# AusperBio

> AusperBio — AusperBio Therapeutics, Inc. in the United States and Ausper Biopharma
> Co., Ltd. (杭州浩博医药有限公司) in Hangzhou, China — is a clinical-stage biopharmaceutical
> company founded in 2019 that develops oligonucleotide and targeted delivery
> technologies, with an initial focus on a functional cure for chronic hepatitis B.
> Its Med-Oligo antisense oligonucleotide (ASO) platform pairs novel ASO design with
> targeted delivery conjugation chemistry; its Au-HALO hepatocyte-targeting technology
> extends the same modular approach to siRNA. Lead candidate AHB-137 completed
> enrollment in two Phase II trials and has China CDE clearance for Phase III; AHB-171
> is a second clinical candidate. AusperBio sells therapeutics, not software: as of
> 2026-08-06 it publishes no public API, no developer portal, no SDK, and no
> machine-readable API contract.

## APIs

AusperBio publishes no public API. Contract discovery on 2026-08-06 probed
www.ausperbio.com and the backend host cms.ausperbio.com for OpenAPI, Swagger,
springdoc/knife4j API descriptions, GraphQL, MCP, llms.txt and A2A agent cards.

The corporate site is a Vue single-page application that answers HTTP 200 with a
2,601-byte shell for every path, including paths that do not exist — so a 200 there is
not evidence of a document. The only machine-readable API description that exists is
the springdoc description of the private Spring Boot CMS that renders the marketing
site (`cms.ausperbio.com/jzy-admin/`), and it is correctly locked behind
authentication. That backend is internal infrastructure, not a product surface.

See the `x-coverage` block in apis.yml for the probed URLs and their HTTP statuses.
